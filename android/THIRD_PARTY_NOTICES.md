# Third-party components

React / React DOM (MIT), Capacitor core/android/App/Keyboard (MIT), Vite (MIT), Lucide-derived SVG icon paths (ISC), Inter (SIL OFL 1.1), Outfit (SIL OFL 1.1), JetBrains Mono (SIL OFL 1.1). Development tools include Acorn (MIT), acorn-walk (MIT) and Playwright (Apache-2.0).

Versions are locked in package-lock.json. Original supplied CSS, branding, render markup and icon path arrays are reused at the user's request; ownership/licensing of that source was not supplied. Original bundled third-party React and JSZip implementations are not copied into the generated app; fresh React dependencies are used and no APK ZIP parser is included.
